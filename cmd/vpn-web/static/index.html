ПОДКЛЮЧЕНИЕ ЗА ТРИ ШАГА

Установили. Активировали. Подключили.

  1. 01

    Установите приложение

    На Android разрешите установку APK из вашего браузера. На Windows запустите установщик и один раз подтвердите UAC.

  2. 02

    Получите личный QR

    Отдельный Telegram-бот выдаёт подписанный персональный ключ. Откройте QR-ссылку на устройстве или вставьте ключ в приложение.

    Бот ещё настраивается
  3. 03

    Нажмите «Подключить»

    Подтвердите системное разрешение VPN на Android. Приложение проверит доступ и покажет реальный статус соединения.

ПОНЯТНЫЕ ПРИНЦИПЫ

Личный доступ. Открытый код.

Ключи не общие

Для каждого пользователя — отдельный подписанный доступ. Установка привязывается к собственному криптографическому ключу, а не к IMEI.

Без журналов содержимого

Мы не сохраняем payload VPN-трафика. Служебные сетевые метаданные нужны для диагностики и хранятся до 72 часов с ограничением объёма.

Без скрытой аналитики

Нет рекламных SDK и сторонних трекеров. На сайте — только собственные счётчики просмотров и запросов загрузки; они не равны числу установок.

Не обещаем невозможного

Используется Chameleon/CITP; Android поддерживает автоматический KS fallback. Нет гарантии обхода любой блокировки, полной анонимности или отсутствия DPI.

Перед первым подключением

Что входит в бесплатный план?

До двух установок на персональный ключ. Срок доступа по умолчанию — 30 дней с продлением через бота. Доступ зависит от ёмкости нод; это предварительный релиз.

Почему Android предлагает включить VPN?

Это обязательное разрешение системы для создания защищённого сетевого интерфейса. Приложение не запрашивает доступ к контактам, микрофону, геолокации или камере.

Что делать, если соединение не установилось?

Проверьте обычный интернет и срок персонального ключа, затем повторите подключение. APK и Windows-сборку сначала нужно проверить на реальном устройстве. Статус «переподключаемся» не означает, что трафик уже доставляется.

Почему установщик Windows не узнаётся SmartScreen?

Для предварительных сборок пока нет коммерческой подписи Authenticode. Скачивайте только с этого сайта и сверяйте SHA-256. APK подписывается отдельным release-ключом, не Android Debug.

Можно ли проверить исходники?

Да. Репозиторий Chameleon-CITP-VPN на GitHub ↗. Лицензии компонентов, сборка и ограничения описаны в репозитории.
